# Project Glossary

This glossary is the authoritative terminology reference for the Persian translation of **Beyond Coding** by David Tuffley.

Its purpose is to maintain consistent translations of technical, professional, and context-sensitive terminology throughout the project.

---

## Usage Guidelines

Before translating an important technical or professional term, check this glossary for an existing translation decision.

If a term is already listed, the established Persian translation should normally be used throughout the project.

A new glossary entry should be added when:

- an important technical or professional term appears for the first time;
- multiple Persian translations are possible;
- the selected translation may affect terminology in later chapters;
- the English term needs to be retained alongside the Persian translation;
- additional context is needed to explain a translation decision.

The glossary should not attempt to include every English word appearing in the book. It should focus on terminology for which consistency or translation decisions matter.

---

## Translation Conventions

When an important term appears for the first time in the translated text, the preferred format is:

> مهارت‌های نرم (Soft Skills)

After its first introduction, the established Persian equivalent may normally be used without repeating the English term.

The English term may continue to be used when:

- there is no clear or widely accepted Persian equivalent;
- the English term is commonly used by Persian-speaking IT professionals;
- retaining it improves technical clarity;
- the context requires distinguishing between closely related concepts.

## Glossary Structure

Each glossary entry contains the following information:

| Column | Description |
| --- | --- |
| English Term | The term as it appears in the original book |
| Persian Translation | The preferred Persian equivalent used in this project |
| First Use | The chapter or section where the term is first introduced |
| Notes | Additional context, alternatives, or reasoning behind the translation decision |

## Terminology Review

Terminology decisions may be revised when a more accurate, natural, or widely accepted translation is identified.

When an existing term is changed:

1. Update the corresponding entry in this glossary.
2. Review previous occurrences of the term in translated chapters.
3. Update affected translations where necessary.
4. Ensure that the revised terminology remains consistent throughout the project.

Significant terminology changes should be documented in the repository history.

---

## Relationship to the Translation Guide

This glossary should be used together with [`TRANSLATION_GUIDE.md`](TRANSLATION_GUIDE.md).

The Translation Guide defines the overall translation principles and workflow, while this glossary records the terminology decisions made during the translation process.

In case of uncertainty, terminology decisions should be evaluated according to the principles defined in the Translation Guide.
